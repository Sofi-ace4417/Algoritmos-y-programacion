# Algoritmos-y-programacion
El proyecto consiste en el desarrollo de un juego interactivo en Python diseñado para simular, validar y resolver el clásico juego de Sudoku.  Está estructurado sobre una cuadrícula bidimensional de 9 x 9 espacios, la cual se subdivide visual y lógicamente en nueve bloques internos de 3 x 3 casillas.  

El propósito principal del proyecto es ofrecer una plataforma digital donde el usuario pueda interactuar con rompecabezas de diversos niveles de dificultad, aplicando el razonamiento deductivo y el proceso de eliminación en lugar de hacer suposiciones al azar. 

El núcleo funcional del programa se basa en el cumplimiento estricto de las reglas tradicionales del Sudoku, asegurando que cada fila, columna y subcuadrícula de 3 x 3 contenga de manera exclusiva los números del 1 al 9, sin permitir duplicados.  

Para garantizar una experiencia fluida, el sistema integra un validador en tiempo real que comprueba cada número ingresado por el jugador, identificando de inmediato si un movimiento viola la consistencia lógica del tablero. Asimismo, distingue entre las casillas iniciales o fijas del rompecabezas y las celdas editables por el usuario, evitando modificaciones accidentales en la configuración inicial.  

Finalmente, la plataforma combina una interfaz visual limpia que ofrece controles de juego como cronómetro de partida, contador de errores y generación de nuevos tableros.
